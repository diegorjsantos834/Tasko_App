## O que você precisa

- [Node.js](https://nodejs.org) (versão LTS)
- Um celular Android com o app **Expo Go** (Play Store) **ou** um emulador Android
- Celular e computador no **mesmo Wi-Fi** (se for usar o celular)

## Como rodar

**1. Baixe o projeto**

Se recebeu o projeto em um `.zip`, descompacte e abra o terminal dentro da pasta.

**2. Instale as dependências**

```bash
npm install
```

**3. Inicie o servidor**

```bash
npx expo start
```

**4. Abra o app**

- **No celular:** abra o Expo Go e leia o QR code que aparece no terminal.
- **No emulador:** deixe o emulador aberto e aperte `a` no terminal.
